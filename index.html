ڕێکخستنی کۆدی چالاککردن (API Key)

بۆ بەکارهێنانی سەرجەم خزمەتگوزارییەکانی ئەم سیستمە پێویستت بە کۆدی (Google Studio Ai) دەبێت. لێرە دەتوانیت کۆدەکەت پاشەکەوت بکەیت بۆ ئەوەی هەموو جارێک پێویست نەکات داغڵی بکەیتەوە. کۆدەکە بە سەلامەتی تەنها لەناو ئامێرەکەی خۆتدا پاشەکەوت دەبێت.

بە Gmail بچۆرە ژوورەوە بۆ ئەوەی کۆدی API و دەقەکانت لە هەژمارەکەتدا بمێننەوە و لە هەر ئامێرێکدا بیانبینیتەوە. هەر کاتێک ویستت، دەتوانیت هەموو داتاکانت بسڕیتەوە.

دەنگی سەرچاوە (١٠ بۆ ٣٠ چرکە)

دەنگی ڕەزامەندی

ئەم دەستەواژەیە بخوێنەرەوە:

یاریدەدەری زیرەک بۆ مامۆستایان و خوێندکاران

بابەتێکی درێژ یان وانەیەک بنووسە. سیستمەکە بە شێوەیەکی زیرەک کورتەی دەکاتەوە، خاڵە گرنگەکانی جیا دەکاتەوە، وە بە زمانێکی زۆر سادە بۆتی ڕوون دەکاتەوە. دواتریش دەتوانیت گوێی لێ بگریت یان تاقیکردنەوەی هەڵبژاردنی بۆ دروست بکەیت.

تاقیکردنەوەی هەڵبژاردن (٣ ئاست)

لە دەقی سەرەوە پرسیاری هەڵبژاردن دروست دەکات: ئاستی یەک ئاسان، ئاستی دوو ناوەند، ئاستی سێ زۆر قورس. دوای هەڵبژاردنی وەڵامەکان، ئەنجامی گشتی دەبینیت.

گۆڕینی دەنگ بۆ نوسین (Speech-to-Text)

١. دەنگی خۆت دابنێ یان تۆمار بکە

٢. ئەنجامی نوسینەکە

سکانکردن: گۆڕینی تێکستی ناو وێنە بۆ تێکستی نووسین

وێنەیەک هەڵبژێرە یان بە کامێرا وەریبگرە (پەڕەی کتێب، بەڵگە، تابلۆ...). سیستمەکە تێکستەکەی دەخوێنێتەوە و دەیکات بە نووسینی دەستکاریکراو.

دەنگی ئامانج (کەسە نوێیەکە)

چاککردنی دەنگ و ئیکۆ (Audio Enhancer)

زیادکردنی ئیکۆی جوان بۆ قورئان و شیعر، یان لابردنی نۆیز، دەنگی عام (hum)، دەنگی ڕووم (echo). هەروەها دەتوانیت دەنگەکە ببڕیت (کرۆپ) و بەشی هەڵبژێردراو بە جیا دابگریت. هەموو کارەکان لە وێبگەڕەکەی خۆتدایە.

٢. ڕێکخستنەکان

٣. ئەنجام (پلەیەر و شەپۆل)

دروستکردنی ڤیدیۆ (Video Studio)

ڤیدیۆی هەواڵ لە ستۆدیۆ یان ڕیکلام دروست دەکات: دەقی بەشی (نوسین بۆ دەنگ) بەکاردەهێنێت بۆ تۆمارکردنی ڤیدیۆیەک لەگەڵ ناونیشان و ڕیزی هەواڵ.

پشت بەستوو بە زیرەکی دەستکردی گووگڵ. تەنها دەقەکەت بنووسە و کلیک لە دوگمەی وەرگێڕان بکە!
